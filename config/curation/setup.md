# justn의 개발 세팅

AI 코딩 에이전트 여러 개를 동시에 굴리는 데 맞춘 세팅입니다.

**터미널과 작업 공간**

- [Herdr](https://herdr.dev): 코딩 에이전트용 터미널 멀티플렉서. 프로젝트마다 워크스페이스, 작업마다 git worktree를 엽니다.
- Ghostty + [ily-sexy-ghostty](https://github.com/justn-hyeok/ily-sexy-ghostty): 터미널과 테마 설정.
- [connect-my-world-in-herdr](https://github.com/justn-hyeok/connect-my-world-in-herdr): 서버·작업 공간을 메뉴 막대에서 다시 연결하는 앱.

**코딩 에이전트**

- Codex를 주 오케스트레이터로, Claude Code·opencode(oh-my-openagent)·Cursor CLI를 함께 씁니다.
- [brgr](https://github.com/justn-hyeok/brgr): 여러 에이전트에게 작업을 맡기고 결과를 검토·적용하는 도구.
- [agent-progress](https://github.com/justn-hyeok/agent-progress): 에이전트의 작업 계획을 옆 창에 보여 주는 진행 표시.
- [agent-config-one-shot](https://github.com/justn-hyeok/agent-config-one-shot): 공용 스킬과 에이전트별 설정을 한 번에 연결.
- [meter](https://github.com/justn-hyeok/meter): AI 코딩 도구 사용량을 메뉴 막대와 CLI로 보여 줍니다.

**라피**

- [rapi-agent](https://github.com/justn-hyeok/rapi-agent): 이 채널들을 채우는 개인 비서. 소식 수집·요약·일정과 자동 배포까지 직접 운영합니다.

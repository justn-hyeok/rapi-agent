# Rapi v0.1.2

보존기간이 지난 수집 메타데이터와 종료된 발송·승인·실행 기록을 자동으로 정리하고,
90일 지난 발송 수신자와 중복 키를 전용 HMAC으로 축소합니다. 진행 중인 실행·발송과
웹훅은 보호합니다. 과거 삭제된 이벤트를 다시 수집하지 않으며 필요한 비밀키가
없으면 수집을 중단합니다.

`/데이터삭제 요청 → 확정 → 상태`로 본인 정보 또는 소유자의 수집 항목·수집원을
처리합니다. 별도 확정 전에 삭제하지 않으며 권한·사용자·서버·확정 기한을 확인합니다.
DB 작업이 확정된 뒤 등록 파일을 처리하고, 중단된 파일 작업은 이어서 처리합니다.
기존 백업이 실제로 없어지기 전에는 삭제 요청을 완료하지 않습니다.

백업과 삭제의 잠금, 추적 ledger의 쓰기 잠금, 영속 게시물 철회와 백업 사본 catalog를
연결했습니다. Migration 0013과 데이터 처리 전 스키마 rollback 절차를 포함합니다.
대화 답변의 요청자를 기록해 본인 대화와 다른 사람의 대화를 구분합니다.

VM 전원·재부팅 작업은 수행하지 않습니다. 사용자 프로젝트, 외부 수신자의 메일함,
Git 릴리스 이력은 삭제 요청 대상에 포함하지 않습니다. 보존 정책과 운영·복원 시
재조정 절차는 `docs/data-lifecycle.md`에 있습니다.

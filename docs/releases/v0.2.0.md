# Rapi v0.2.0 — a daily briefing, a curated community and a researched chatbot

The first release since v0.1.2. It covers the product rebuild (D-012 onward) and
everything shipped through 2026-10-28. The `v0.1.3` notes that were drafted but never
tagged described the Mac Aside collector, which was removed (D-011); they are dropped.

## What people see

- **Daily briefing** as a Discord card plus a private web page, ranked by learned
  preference, with in-page detail summaries. Repository activity is grouped, and
  unfamiliar repositories are introduced.
- **Schedule** (`/일정`) with collected contest, hackathon and CFP deadlines.
- **Curation channels** for projects, setup repositories, AI blogs and free-token news.
  Project and setup posts are owner-reviewed drafts; AI blogs are grouped one card per
  source.
- **Chatbot** answers from the collected archive: keyword search, LLM query expansion
  and rerank, plus an optional graph index. It says so when evidence is weak.
- **Help channel** with a usage guide, and Markdown tables in replies shown as lists.
- **Reports and notices as Discord embeds**: GitHub weekly report, learner weekly
  report, blog draft approval, harness updates, learner preview and issue DMs, and new
  server approval. Pressed buttons keep the card and append a result card.
- **Readable text everywhere**: HTML tags and entities in feed titles and summaries are
  stripped before they reach Discord, mail or the web page.

## Operations

- Main is deployed automatically after CI, with a rollback receipt per switch.
  A deploy fails if it makes more sources fail than before; transient source outages
  do not block it.
- Crawler and Mac Aside collection are removed; all collection runs on the VM through
  feeds and APIs.
- Owner-only read-only browser research, a guide composer (LangGraph) for blog drafts,
  and an n8n announcement workflow with signed events are included.

## Off by default

Billing (Toss Payments period passes) waits for business registration. Browser research,
harness (senpi) update notices and the n8n owner account are not enabled. Each is behind
a flag documented in `docs/`.

## Upgrade

Apply the migrations in `packages/db/migrations/` (each has a file in `packages/db/rollbacks/`). No manual step is
required for a deployment that follows main.

# Rapi v0.1.0

Discord에서 공개 커뮤니티의 질문·검색·브리핑과 소유자의 승인된 개인 작업을
사용할 수 있다. RSS와 GitHub 수집, 주간 Discord·메일 브리핑, 공개 MDX 블로그를
연결하고 재시작·중복 발송·취소 복구를 보강했다.

- USER/ADMIN 권한과 공개 진입점의 서명·사용량 제한을 적용했다.
- 자연스러운 라피 호출과 즉시 입력 중 표시를 지원한다.
- Gmail 발신 별칭과 유효한 Message-ID를 사용하며 실제 수신함에서 검증했다.
- MDX의 실행 코드·raw HTML·위험한 URL을 차단하고 비공개 글을 공개 출력에서 제외한다.
- Codex 실행·실제 취소와 복원된 DB를 사용한 앱 기동을 검증했다.
- 서버 밖 공개 endpoint 감시와 Discord 장애·복구 알림을 추가했다.
- 백업을 30일 보관하고 DB 데이터의 일일 만료 대상 inventory를 추가했다.
- GitHub CI에 모바일·데스크톱 블로그 브라우저 검증을 추가했다.

Node.js 22.13 이상과 PostgreSQL 16이 필요하다. 운영 비밀값, Google/Discord 인증,
Cloudflare tunnel은 저장소에 포함하지 않는다. 개인 Codex 실행 계정과 공개 응답
계정은 별도 구성한다. 새 DB는 migration을 실행하고 runtime 권한을 적용해야 한다.

DB 원문 자동 삭제 executor와 실제 VM 전원 차단 검증은 포함하지 않는다.
예약 GitHub Actions 감시는 엄격한 가용성 SLA를 제공하지 않는다.
현재 적용과 검증 기록은 `docs/evidence/full-runtime-20260928.md`와
`docs/operations-reinforcement.md`를 참조한다.

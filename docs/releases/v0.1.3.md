# v0.1.3 — Aside browser collection

Adds an approved Hacker News browser source collected by the existing Aside
installation on the Mac and delivered to the Linux VM over SSH. Collection is
private, serial, capped at 30 stories, polled every 15 minutes, and records
source page, capture time, and browser provenance. It reads only its own page
and closes its own tab.

Server leases expire after 3 minutes; replaced/expired tokens are rejected.
All items and the success cursor commit together. Failures retry with bounded
backoff, and unsupported or stale sources cannot claim healthy readiness.
Existing privacy tombstones, content retention and deduplication apply.

The Mac launch agent checks for work every minute. Browser collection requires
the Mac to be awake, its login session available, and Aside reachable. It does
not install Aside on Linux, collect arbitrary authenticated websites, or copy
browser credentials. RSS and GitHub remain independent.

See [Aside collection](../aside-collection.md) for operation and recovery.

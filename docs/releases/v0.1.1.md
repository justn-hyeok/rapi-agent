# Rapi v0.1.1

운영 서버에서 공개 원본은 90일, 비공개 원본은 30일 뒤 본문을 만료한다.
원본에 연결된 요약·분류도 삭제하고 검색·발송에서 만료 항목을 제외한다.
아직 발송 중인 항목은 보호한다.

원본이 만료된 기존 공개 글은 함께 철회한다. 게시물 URL은 404로 전환하고,
목록과 RSS에서도 제거한다. 철회 상태는 릴리스 밖의 영속 파일에 저장하므로
이전 버전의 정적 파일이나 소스가 남아 있어도 공개 gateway가 재공개하지 않는다.
철회 상태 파일이 손상되거나 없으면 공개 블로그는 닫힌다.

자동 만료는 26시간 이내 성공한 실제 백업이 있을 때만 실행한다.
실패·미실행은 기존 monitor의 상태·장애 알림에 반영한다.
코드·설정·보호 규칙은 PR 및 CI 검증을 거쳐 반영한다.

이 릴리스는 원본 본문, 연결된 파생 내용과 공개 게시물의 만료를 자동화한다.
1년 감사 메타데이터의 최종 제거, 수신자 식별자 축소, 사용자 삭제 요청의 백업
추적은 일일 inventory 대상이며 별도 구현 범위다.

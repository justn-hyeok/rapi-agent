상태: accepted (2026-09-08, repository owner implementation directive)

| 데이터                              | 기본 보존 | 삭제 방식                                                   |
| ----------------------------------- | --------: | ----------------------------------------------------------- |
| 원본 공개 feed/GitHub 이벤트        |      90일 | 만료 worker가 본문을 삭제하고 checksum·출처·시각은 1년 보존 |
| Discord DM·Aside·비공개 저장소 원문 |      30일 | 본문과 첨부 삭제, 최소 감사 메타데이터 90일 보존            |
| 요약·분류 결과                      |     180일 | 근거 원문 삭제 시 재공개를 금지하고 정책에 따라 함께 삭제   |
| 발송 기록                           |       1년 | 수신자 주소는 90일 뒤 비가역 해시 또는 별도 식별자로 축소   |
| 승인·외부 실행 감사 기록            |       1년 | 작업 결과에서 비밀값과 불필요한 원문을 먼저 제거            |
| 백업                                |      30일 | 순환 만료하며 삭제 요청은 다음 백업 만료 시점까지 추적      |

백업 만료 예정일 기록 순으로 처리한다. 최종 기간은 실제 데이터량과 복구 요구를
측정한 뒤 ADR로 확정한다.

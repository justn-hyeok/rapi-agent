# UX 메모 (b-multi-guild)

- (U8에서 고침) `[허용]`/`[거절]`을 누르면 요청 메시지 자체가 결과(누가, 언제, 허용·거절)로 바뀌고 버튼이 사라집니다. 이미 처리된 버튼을 다시 눌러도 같은 방식으로 "이미 처리했거나 요청이 없는 서버입니다"가 보입니다.
- (U8에서 고침) 허용되지 않은 서버에서는 승인 대기 중이며 서버 주인이 라피 운영자에게 허용을 요청해야 한다고 안내합니다.
- (U8에서 고침) 일반 서버 관리자가 전역 명령을 쓰면 그 서버에서 쓸 수 있는 `/사용정책`, `/서버구성`, `/대화채널`, `/대화해제`를 알려 줍니다. 웹이 켜져 있으면 앞의 두 명령은 웹 링크 안내만 합니다.
- slash 명령은 서버별로 등록되므로, 허용된 서버에는 허용 직후 등록합니다. 등록이 실패하면 안내 문구만 나오고 자동 재시도는 없습니다.
- 서버를 거절하면 라피가 바로 나갑니다. 실수로 눌러도 되돌릴 수 없고 서버 관리자가 다시 초대해야 합니다.
- (U8에서 고침) `[허용]` 결과 메시지가 다음 단계(그 서버에서 `/서버구성`, 웹이 켜져 있으면 `/admin/server-config`)를 알려 줍니다. 서버 주인에게 전달하는 것은 여전히 운영자 몫입니다.

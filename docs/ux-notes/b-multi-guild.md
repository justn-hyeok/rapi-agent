# UX 메모 (b-multi-guild)

- 허용 요청 DM의 `[허용]`/`[거절]` 버튼을 누르면 원래 메시지는 그대로 남고 별도 임시 응답만 뜹니다. 눌렀는지 한눈에 알기 어렵고, 같은 버튼을 다시 누르면 "이미 처리했거나 요청이 없는 서버입니다"가 나옵니다. 버튼 메시지를 결과로 갱신(버튼 제거)하는 편이 낫습니다.
- 허용되지 않은 서버의 slash 명령은 "아직 허용되지 않은 서버입니다."만 보여주고, 누구에게 요청하면 되는지 안내가 없습니다.
- 일반 서버의 관리자가 `/수집원`, `/상태` 등을 쓰면 "운영자 서버나 DM에서만 사용할 수 있습니다."로 거절되는데, 그 서버에서 쓸 수 있는 명령 목록은 보여주지 않습니다.
- slash 명령은 서버별로 등록되므로, 허용된 서버에는 허용 직후 등록합니다. 등록이 실패하면 안내 문구만 나오고 자동 재시도는 없습니다.
- 서버를 거절하면 라피가 바로 나갑니다. 실수로 눌러도 되돌릴 수 없고 서버 관리자가 다시 초대해야 합니다.
- 새 서버의 피드 채널은 `/서버구성` 적용 뒤에야 생깁니다. 허용 후 이 단계를 안내하지 않아 피드가 오지 않는 이유를 알기 어렵습니다.

# UX 메모 (a2-harness-adapters)

- `/ready`의 senpi 항목은 바이너리와 설정 파일만 보므로 `ok`여도 공급자 로그인이 안 된 상태일 수 있습니다. (U8에서 고침) 로그인 전 `센파이로 …`가 인증 오류처럼 보이는 출력으로 실패하면 "senpi 로그인이 필요할 수 있어요: docs/operations.md 참고"를 덧붙입니다. 출력에 인증 관련 단어가 없는 실패에는 붙지 않습니다.
- (U8에서 고침) 소유자가 아닌 사람이 `센파이로`/`senpi:`로 시작하면 "하네스 선택은 소유자만 쓸 수 있어요" 한 줄을 먼저 보여 주고, 접두사는 그대로 둔 채 요청을 평소처럼 처리합니다. 접두사가 질문 문장에 섞여 들어가는 점은 그대로입니다.
- 접두사 두 개(`센파이로 아스트라로 …`)를 이어 써야 하는 점이 번거롭습니다. senpi는 Codex 모델 별칭이 아닌 `provider/id`를 받는데 현재는 명시한 모델명을 그대로 넘깁니다.
- 대체 실행(Codex) 안내는 답변 첫 줄에만 있고 실행 기록(상태 조회)의 모델 칸에는 하니스가 나오지 않습니다.

# UX 메모: 학습자 DM 실험

- 옵트인 안내 메시지는 채널에 올라가므로, 버튼을 누르면 빈도 선택(임시 메시지)을 한 번 더 거친다. 두 단계가 필요하지만 한 번에 빈도까지 고르게 하려면 버튼을 둘로 나눠야 해서 안내가 길어진다. 첫 실험은 두 단계로 둔다.
- DM이 닫혀 있거나 서버를 공유하지 않으면 발송이 실패하고, 학습자에게는 알려 줄 방법이 없다. 신청 확인 문구에 "서버 멤버 DM 허용"을 적었지만 실제 확인은 첫 발송 뒤 운영자 보고(성공·실패 인원)로만 알 수 있다. 신청 직후 확인 DM을 한 통 보내는 방안은 1단계에서 검토한다.
- 호 발송은 DM 버튼으로 승인하므로 운영자가 미리보기를 놓치면 그날 호는 나가지 않는다. 리마인드는 두지 않았다. 건너뛴 호의 항목은 다음 호에 합쳐지지 않고 사라진다.
- 큐레이션 채널에 자동 게시된 글은 임베드가 저장되지 않아 호에 들어가지 않는다(승인한 초안만 링크가 남는다). 무료 모델 신규 알림만 "새 무료 모델 N개"로 묶어 넣는다. 호가 비는 날이 많으면 이 부분을 먼저 본다.
- 공유 횟수는 측정할 수 없어 리포트의 "답장·공유 2건"은 답장만 센다. 공유는 운영자가 직접 확인해야 한다.

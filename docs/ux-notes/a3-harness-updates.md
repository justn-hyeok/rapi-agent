# A3 하네스 버전 갱신 UX 메모

- `[반영]`을 눌러도 곧바로 설치되지 않는다. PR 머지 → 자동 배포 → VM에서 `scripts/install-senpi.sh` 실행까지 세 단계가 더 남아 있어, 소유자가 마지막 수동 단계를 잊기 쉽다. 머지 알림 DM에 설치 명령을 적어 두었지만 자동 설치(배포 단계 연결)가 필요한지 판단이 필요하다.
- 스모크 프롬프트는 서비스 계정의 로그인 정보를 임시 디렉터리로 복사해야 통과한다. 로그인 전에는 항상 `보류 추천`이 나와 이유가 "스모크 프롬프트 실패"로만 보인다.
- 평가 DM에는 호환성 변경 요약이 최대 5건까지만 보인다. 전체는 릴리스 링크로 확인해야 한다.
- 닫힌(머지 안 된) PR은 `건너뜀`으로 기록되고 DM이 오지 않는다. 같은 버전을 다시 올리려면 DB를 직접 고쳐야 한다.
